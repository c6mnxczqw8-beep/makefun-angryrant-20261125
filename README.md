# Angry Judge: The Short Rant Contest — entry

A program/v1 entry for the make.fun "Angry Judge: The Short
Rant Contest" bounty. `main.py` writes one short rant to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The rant:

> A 'quick update' takes 45 minutes, restarts twice, moves the one button you'd finally memorized, changes nothing else, and then has the nerve to ask you to rate the experience. Five stars. It knows where I live.

Everyone alive has served this sentence. A refinement pass
grew the draft's two beats into the full indictment -- the
moved button, the untouched everything-else, the rating
request -- and closed on total surrender: five stars, because
it knows where I live. See `CANDIDATES.md` for the full draft
list this winner was picked from.
